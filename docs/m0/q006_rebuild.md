# Q-006 — 邻居列表重建间隔定标(Q-006/6b/6c 清零)

**登记**:spec §5.2 / §14.1 Q-006、Q-006b/c(原 `~X fs` 占位);本文给出实测值、
标度验证、一个已修复的体系构建缺陷(PME α 单位地雷),与一项待裁决的规格张力。
实验:`experiments/q006_rebuild/`(run_q006.py / analyze.py / results/)。

## 1. 方法摘要

- **仪器(E0a 纪律)**:OpenMM 8.6 CPU 平台积分(A1 已证 opus↔OpenMM 能量/力
  逐项一致 rel<1e-10;opus 引擎 direct_space 逐对 Python 循环,N=1020 单次力计算
  23.7 s,200 ps 不可行)。位移统计为事后纯运动学量,与积分器实现无关。
- **体系**:TIP3P-FB 刚性水,PME α=3.5 nm⁻¹,rc=1.0 nm,300 K,
  LangevinMiddle(BAOAB 族)γ=1 ps⁻¹;HMR×3 臂与无 HMR 臂;box ∈ {2.2, 3.0, 3.6}³
  (N = 1020/2640/4515);最小化(G3b 纪律)→ 10 ps 熔化@2fs → 切目标步长 →
  16 ps MSD 液体自检门(MSD_O@16ps ≥ 0.10 nm²,防玻璃态数据静默入库)→ 测量。
- **重建判据**(spec §5.2):`max_a |x − x_ref| > d_thresh`,d_thresh = 0.05 nm,
  越界即回置(renewal 语义);全原子与重原子(质量>3.5,排除 HMR×3 后的 H=3.02)
  两套独立参考点。masking 严格(柱 5)⇒ 重建事件不改变轨迹值 ⇒ 单轨迹多 d 分析。

## 2. 排查记录:PME α 单位地雷(已修复,登记为雷区类发现)

初版数据 MSD_O 低文献 30×(似玻璃)。二分排查(每臂 10–20 ps 平衡 + MSD@16ps,
液体参照 ≈0.22 nm²):

| 配置 | MSD_O@16ps | 判定 |
|---|---|---|
| dt2 无HMR 无钉参 无最小化 | 0.207 | 液体 ✓ |
| dt2 无HMR 无钉参 **+最小化** | 0.189 | 液体 ✓(最小化器无辜) |
| dt2 无HMR **+钉α=0.35/nm** | 0.013 | 玻璃 ✗ |
| dt2 **+HMR** +钉α | 0.011 | 玻璃 ✗ |
| dt4 +HMR **无钉参** | 0.143 | 液体 ✓ |

**根因**:`setPMEParameters(0.35/nm)` 是 AMBER `0.35 Å⁻¹` 的单位错位(应 3.5 nm⁻¹)。
erfc(0.35)=0.62 ⇒ 直空间静电在 rc=1.0 处被截 62%,水锁死不扩散。M0.5 fixture
(`tests/test_m05_dynamics.py:218`)同值,但其 20 步 SHAKE 测试不涉物理,已加 WARNING
注释(测试行为不变,8/8 green)。**教训登记**:G4「钉 PME」门只验证"钉了",不验证
"钉得物理"——建议补 α·rc ≥ 3 合理性子句(见 §6)。

## 4. 标度验证(定标的外推资格)

1. **弹道机制(非扩散)**:H 质量 ×3 ⇒ 全原子 renewal 10.8→18.8 fs,比值 1.74
   ≈ √3 = 1.732 ✓。d=0.05 nm 处于短时弹道/转动区(t ≈ d/(v·√(2 ln N))),
   **spec 原设 t ∝ d²/D(扩散主导)在此尺度不适用**;扩散模型仅当 d ≳ 笼尺度
   (~0.15–0.2 nm)才可能接管。
2. **ln N 极值标度**:全原子 rate 53.2→60.0(N 1020→4515),预测 65.4(∝ln N),
   实测 +12% vs 预测 +23%——方向与量级相符(笼相关性压低)。
3. **步长无关性(物理时间)**:重原子 ✓(§3 Q-006c)。
4. 种子稳健性:s2 臂与主臂差 <1%(53.3 vs 53.2;41.1 vs 41.2)。

## 5. 规格张力(交用户裁决,不单方面改冻结决策)

实测在 **两种监控语义下 P(越界@K=25 窗口) = 1.000** ⇒ C1 flag 每窗必触:
「flag 是性能事件」退化为「每窗回滚风暴」,且 K 收缩梯 {25,12,6} 到底也无法平静
(K=6@4fs = 24 fs ≈ 全原子 renewal 18.8 fs / 重原子 41 fs,仍高概率触发)。
另:全原子 100 fs 窗口 p95 位移 0.19–0.25 已超 s_window 0.12 预算(P=1);
K=50 时全原子 p95 = 0.29–0.33 > skin 0.28——**列表失效风险**(spec 自注
「K=50 必触发」获定量确认,且更严重)。

选项(供决策,数值均出自 §3):
- **(a) 重原子监控 + d_thresh 提至 0.13–0.14 nm**:100 fs 窗口重原子 p95
  0.117–0.135、p99.9 ≤0.144 ⇒ P(flag)≈p95 外尾,flag 回归「罕见性能事件」;
  代价:skin 分解重推(Q-005),H 位移需靠刚性几何约束间接保证(限刚性水+约束 H)
- **(b) 保持全原子 0.05,flag 改为哨兵(不回滚)**:正确性改由重建频率承保
  (rebuild 每窗边界 + 全原子 renewal ~60/ns ⇒ 实际重建间隔 ≲17 fs,列表半径
  需 cover 2×0.05;性能损失大)
- **(c) K 降至 4–6 常态 + d=0.05**:renewal 仍 ≈ 窗口长,flag 率 ~50%,不可行

登记为 spec 开放项 7;影响 §5.2(skin 分解)、§7(K 定位)、M13/M14 构造。

## 6. 副产登记

- **G4 门语义补强建议**:钉 PME 需含 α·rc ≥ 3(erfc 截断 ≤ 2e-5)合理性子句;
  本次单位地雷(0.35/nm)即该子句将抓的模式
- D_heavy 顺带测定:1.5–1.9×10⁻³ nm²/ps(γ=1 Langevin 阻尼 + 2–4.5 ps 拟合窗
  偏保守,文献 TIP3P-FB ≈ 2.3×10⁻³,量级一致)
- opus 引擎性能注记:direct_space 逐对 Python 循环,N=1020 单次 23.7 s——
  参考实现按设计不为速度优化;任何动力学用途需外部仪器(本文件 §1)
