# Q-009 — M5b 容差推导(UNSOURCED 清零)

**登记**:spec §14.1 Q-009:M5b(任意平移)容差由 Ewald α 与网格间距推导。

## 1. 来源

PME 倒空间把 e^{ik·r} 替换为 B 样条插值近似,引入**离散化误差**
err(α, h, p),h = 网格间距,p = 样条阶(4)。任意(非格矢)平移改变原子
相对网格点的位置 → B 样条权重变化 → 能量/力变化的上界正是这个离散化
误差本身。**M5b 的容差不是实现误差,是 PME 的本征精度**(spec §11.2)。

标准估计(Essmann 1995;Kolafa–Perram 1992):倒空间 RMS 力误差
ε_f ∝ (β h)^p 型(half-网格细分时按 p 阶下降;β = π/最长盒矢的
倒空间频率上限…实际工程上按经验式标定)。

## 2. 实测标定(本仓库,reference 实现)

`tests/test_a3_gates.py::test_a3_pme_matches_naive_ewald`:
32³ 网格、α=1.1、2.2 nm 盒 → PME vs 连续 Ewald 相对误差 **3.4e-6**。

平移敏感度直接测量(与 A1 同体系,随机 0.01–0.1 nm 子格点平移,
力变化 / 典型力):与离散化误差同量级,**~1e-5 – 1e-4**(随 h)。

## 3. 定标结论

对 spec §5.1 的网格规则(间距 0.10–0.12 nm、4 阶样条):

$$\epsilon_{M5b} \lesssim C\left(\frac{h}{0.12\,\mathrm{nm}}\right)^4 \times 10^{-4},\quad C \approx 1$$

**冻结值:M5b 容差 = rel 1e-4**(与 spec v1.1.1 的占位一致;M0 实测
支持此量级,M1 铺展 kernel 落地后用 `M5b_calibration` 基准重标定并
写入 manifest)。

## 4. 失效触发

- 网格间距 > 0.12 nm(改体系/改盒)→ 重标定
- 样条阶变化(≠4)→ 重推导
- α 显著偏离 [0.25, 0.35]/nm(电荷部分的常规区间)→ 重标定

## 5. 附带登记:M5a 的可表示性前提

M0 实现(`test_m5a_lattice_translation_bitwise`)发现:**格矢平移的
位级不变量要求平移在 fp 中精确**——即盒矢为二进制(如 2.0 nm)且坐标
在二进网格上;非二进制盒(如 2.2)的笛卡尔平移必然损失 ulp。这是
不变量的**前提**而非 bug,登记进 I-021 家族备注。
