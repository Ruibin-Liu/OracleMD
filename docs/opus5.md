## 1. 范围与非目标

### 1.1 在范围内

- **输入**:OpenMM System XML + 坐标/盒矢量(唯一入口)

## 2. 数据布局

### 2.1 副本维度为最内层(最重要的单一决策)

$$\texttt{x}[a][r], \quad a \in [0,N), \; r \in [0,R)$$

**R 是编译期模板参数,实例化离散集合 {1, 8, 16, 48, 96};生产二进制固定 R=48。** M4 与 benchmark 随机化在实例化集合内成立;padding 到 8 的倍数适用于非 8 倍数实例。

**收益**(区分三条性质,不可揉写):① **指令流一致**(同一 kernel、同一 tile 循环边界、同一共享列表结构)——永久;② **访存合并**(副本最内层 ⇒ 坐标连续读取,参数基值广播、λ 参数合并读取)——永久;③ **分支判定跨副本不一致**——各副本是独立轨迹,t>0 后坐标各不相同,「副本间仅 λ 不同」只在 t=0 成立。因此 r² 判定、软核开关等同 warp 内必然分歧,**masking 必须无分支(乘 0)**,见 §5.2;邻居列表跨副本共享依赖的是构象分布重叠(t=0 同源 + λ 差异小),不是坐标相同。

**Tile 结构**:[8 atoms] × [8 atoms] × [R replicas]。A100 的 164 KB/SM 共享内存是 tile 搜索空间。

### 2.2 显存预算(N=60000, R=48, 全 fp64)

| 项 | 占用 |
|---|---|

## 3. 精度模型与确定性(五柱)

**单位制(v1.1.2 钉死,源自 M0.5 教训)**:nm / ps / kJ/mol / amu——
kJ/mol/amu = nm²/ps² 自洽;任何新代码不得引入 ns/ps 混用(M0.5 曾因此
把步长跑小 2000× 而产生虚假稳定性)。

### 3.0 五根柱子(全部构造类,全部位级;M0–M3 全部已实现并验证)

**GPU 内核守卫(v1.1.2,M0.5/M3 发现登记)**:近共面二面角几何(直线链,φ→0/π)的梯度表达式在 |A||B|→0 处尖峰——公式正确(mpmath 验证)但实现需退化保护;HREX 重指向后 RNG 必须延续**绝对步计数**(重建 Dynamics 对象不得归零 step,否则噪声流重放致 slot 相关,M6b 的运行时版)。

**实测背景**(A100 80GB PCIe,driver 580.105.08 / CUDA 13.0 / cuFFT 12.x 经 cuPy 14.2):

- fp64 `atomicAdd` 铺展**连 run-to-run 都无位级保证**(同配置 ×5 全部 DIFF,~0.7% 元素,maxrel ~10⁻¹²);int64 Q16.48 跨 block 配置位级相同 ⇒ 柱 2 是 M0 前置,不是增强
- cuFFT fp64 per-transform 数值**与 batch 数无关**(c2c/r2c/c2r,64³–128³ 含非 2 幂,batch {1,4,8,48};SM 竞争与显存压力 1.5 GiB + plan 缓存清空两维下均位级相同)⇒ M1 位级整体可保;`I-012`(实测/监护)记录版本与压力测试

### 3.1 Q24.40 力累加

$$F_{\text{fixed}} = \text{round}(F_{\text{float}} \times 2^{40})$$

范围 ±8.4×10⁶ kJ/mol/nm,分辨率 2⁻⁴⁰ ≈ 9×10⁻¹³。范围论证:`Q-008` **UNSOURCED**(最坏力 = 软核力上限 × 最小允许距离 × 安全因子),阻塞 M0 验收。

**溢出政策**:累加**饱和而非回绕** + 粘滞标志;每次 graph replay 边界检查(**release 也检查**——位级确定系统里回绕是可复现静默反号力,等价断言全部照常通过);ingest 加 max-force 门控(未最小化体系直接拒绝)。

**能量累加(M0 裁决)**:**Q34.30 定点,不用 f64 树**——f64 求和是项序相关的,M6(重排不变)的能量位级只有定点能量能做到;实测 Q34.30 分辨率 9.3e-10 kJ/mol 通过 A1 的 abs 门(1e-8)与 rel 门(大能量项)。溢出检测在**量化前域**(cast 后检查 int64 回绕已成垃圾——B10 的现场版)。

### 3.2 Q16.48 电荷网格

铺展:q_i × B-spline 权重 → 定点 → atomicAdd(int64);定点和是**量化后问题的精确解**(fp64 围绕它随机游走)。选择理由:**确定性与结构同构,非精度优越**(单项量化 2⁻⁴⁸ ≈ 3.6×10⁻¹⁵ 比 fp64 单项舍入约大 30×,赢面在求和不累积)。

范围:4 阶样条权重积 ≤ 1,网格间距 0.10–0.12 nm 下重叠原子 ≲ 30,|q| ≤ 1.5 e ⇒ 网格点电荷 ≲ 45,整数 16 位(±32768)余量三个数量级。**无 clash 敏感性**(铺展权重有界,不随构象发散)——溢出仅需粘滞标志兜底,不需 ingest 门控。定标位数为编译期常量 + 溢出断言保护下可搜索。

### 3.3 归约政策与时钟禁令

> **归约政策(CI 静态可检)**:引擎内任何跨线程的浮点累加都必须走定点,或必须有编译期固定的归约形状。新增任何 `atomicAdd(float/double)` 视为规格违反(grep + 白名单)。

> **时钟禁令(作用域限定)**:**结果路径**(device 全部内核;host 的 HREX/barostat/ALF 判据、checkpoint 写入内容、u_kn 落库、回滚决策)禁止读取任何时钟。**豁免层**(调度、异步 IO、日志、剖析、看门狗、超时重试)可读时钟,但禁止向结果路径回传时间戳或任何时间派生量。CI:①结果路径文件白名单 × 时钟 API 黑名单;②豁免层→结果路径的数据流检查(抓「调度器把超时换算成 n_steps 传给引擎」这类真实泄漏)。

**调度器抢占的纪律(I-022)**:抢占只允许发生在窗口边界,checkpoint 内容与主动 checkpoint 位级相同。**时间只能影响何时停,不能影响停在哪**——后者必须由步数决定。

### 3.4 gate 分类学(两维正交)

- **地板 / 归因**:地板必须二值、无辩解空间;归因必须指定偏离时写入 §14 哪一行。**「地基 × 归因」必须为空**——地基断言不允许「偏离后给归因」。
- **地基 / 探测器 / 监护**:确定性由构造成立(地基);测试抓「地基被绕过」(探测器,失效 → 找那段代码,**不放宽容差**);实测类监护抓「外部世界变了」(失效 → 调查 plan/版本,**不放宽容差**)。
- **统计地板门在确定性栈上不 flaky**(I-020):固定位级种子 ⇒ KS 统计量是确定数。基线值与 manifest 哈希绑定;不匹配报 **error(无法判定)而非 fail(判定为错)**。

**容差形式**:全 A/M 系列采用 abs+rel 双门(湮灭端点/近零处分母发散):|a−b| < ε_abs ∨ rel < ε_rel;ε_abs 按量纲给(力 10⁻⁸ kJ/mol/nm,能量 10⁻⁸ kJ/mol)。

## 4. λ 层 IR(核心差异化)

### 4.1 IR 结构

```
ForceTerm {
  kind     : LJ | Coulomb | Bond | Angle | Torsion | Restraint
  atoms    : [i, j, ...]
  params   : [ParamExpr, ...]        // 参数是表达式,不是数
  softcore : SoftcorePolicy | None
}
ParamExpr = Const(v) | Interp{a, b, schedule} | Scale{base, schedule} | Custom(expr_tree)
Sched     = Linear | SoftcoreOffset | Piecewise | LambdaComponent(i)
```

**非键 λ 语义**(与 §4.6 合并交付):per-atom σ/ε/q 为 ParamExpr,炼金原子对上挂 SoftcorePolicy,「哪些对算炼金对」显式定义。

**轴纪律(雷区 #014)**:所有含批量维的张量在 IR 中携带**命名轴**而非裸 stride,轴运算合法性在 lower 时静态检查。u_kn、∂U/∂λ、铺展网格 [128³×R]、二次型系数 A/B/C 全部是「物理轴 × 批量轴」结构。

### 4.2 ∂U/∂λ 自动微分 + 中心差分 oracle

$$\frac{\partial U}{\partial\lambda_i} = \sum_{\text{terms}} \sum_{p} \frac{\partial U}{\partial\theta_p} \cdot \frac{\partial\theta_p}{\partial\lambda_i}$$

**A6(独立 oracle)**:逐 λ 分量中心差分(δ ~ 10⁻⁵,f64 下 rel 10⁻⁶),在**多个 λ 中间点**测(端点是软核退化点,最不易暴露接线错误)。ingest 层即可做,与 M17 共用 harness。

### 4.3 软核:完整解析定义(冻结)

$$U^{sc} = 4\lambda^{a}\epsilon\left[\frac{1}{\left(\alpha(1-\lambda)^{b} + (r/\sigma)^{c}\right)^{2}} - \frac{1}{\alpha(1-\lambda)^{b} + (r/\sigma)^{c}}\right]$$

**冻结参数:α = 0.5,a = 1,b = 1,c = 6。σ/ε 先组合(Lorentz–Berthelot,作用于 λ 插值后的 per-atom 参数)后软核——次序写死,先软核后组合给出不同能量。**

选择理由:b=1 时 ∂U/∂λ 在 λ→1 处非零有限(b=2 趋零但端点附近窗口浪费);b=1 保持 u(λ) 对 λ 低阶依赖,与 C3 二次型结构兼容;配非均匀 λ 调度(端点加密)是标准组合。

**方向:spec → A2**(openmmtools 的软核指数可配,按本定义配置;不一致时以 spec 公式为准)。§4.6 完整解析定义(M1 已交付,实测锤定):

- 软核公式与全部参数(α=0.5, a=1, b=1, c=6,先组合后软核);
- **decouple 语义(v1.1.2 锤定)**:溶质内部 LJ **恒全耦合**(λ 无关,openmmtools 默认,其 CustomNB 表达式硬编码 lambda_sterics=1.0);静电为**湮灭式**(q(λ)=q_env+λ·q_alch,含溶质内部);湮灭式 LJ(alch_alch_lj='all')保留为 A6 解析扫描选项;
- **alchemical_pme_treatment = 'exact'**(openmmtools 现代默认,非 v1.1 所记的 direct-space)——粒子电荷偏移 q_i(λ) 直接进 PME,A2 harness 配置入 manifest;
- **G5 门**:非中性 PME 体系 ingest 拒绝(净电荷容差 1e-6)——我们的 PME 丢 k=0 项不带中和背景约定,与 OpenMM 差约 20 kJ/mol(雷区 #3 的 ingest 纪律,M1 实测);
- exception 缩放:炼金原子对上的例外 chargeProd 随 λ 缩放(一对一 λ、双炼金 λ²,与母非键项同一插值);
- λ 依赖键(微扰键,M3 交付):k(λ)=kA+λ(kB−kA),∂U/∂λ 解析;
- PME 三处 λ 缩放与 §5.1 同一份定义(倒空间/自能/排除项均 q(λ) 二次型)。

### 4.4 slot / state 二元区分(λ 交换的正确抽象)

| 量 | 归属 | 理由 |
|---|---|---|
| 坐标 x、速度 v | **slot** | 构象不动 |
| λ 向量、ALF 偏置系数 | **state** | 定义 Hamiltonian,在 slot 间置换 |
| MSλD 的 θ、θ̇ | **slot** | 构型自由度(MSλD 与 HREX 互斥,见 §8.2) |
| ∂U/∂λ 累加器 | **state** | 后处理按态聚合 |
| u_kn 行标签 | **state**(列标签是采样时刻) | MBAR 输入语义 |
| RNG 种子的 replica 维 | **slot** | Langevin O 步作用在坐标上;绑 state 则交换后随机力流跳变,破坏细致平衡 |
| permutation 日志 | 全局 | 后处理必需 |

### 4.5 λ 求值与 MSλD

每副本一个 λ^(r) ∈ R^L。参数 kernel 内实时求值(λ-dynamics 下每步变);IR 编译期常量折叠 + lower 成内联算术,不做运行时解释。MSλD:∂U/∂λ 已有 ⇒ λ_i(θ) 与 θ 的 BAOAB 各几十行 host 代码,无需新内核。

## 5. 非键相互作用

### 5.1 PME 与倒空间二次型展开

**空间并列**:R 份网格 + 一次批量 cuFFT(cuFFT plan 参数进 manifest 哈希);PME_TILE ∈ {1,4,8,R} 开关保留,默认 R。网格不可跨副本共享(各副本电荷 λ 缩放不同)。

**PME 三处一致缩放**(雷区 #1/#2,M0 即断言):倒空间、正空间排除修正、自能项。倒空间能量对电荷是二次型——**三项共享同一个 `QuadraticLambdaExpansion` 结构体、同一个 Δq 向量、一次性算出,任何一处单独求值视为规格违反**:

$$E_{\text{recip}}(\lambda) = \underbrace{\textstyle\sum_k S(k)|\rho_0|^2}_{A} + 2\lambda\underbrace{\mathrm{Re}\textstyle\sum_k S(k)\rho_0^*\Delta\rho}_{B} + \lambda^2\underbrace{\textstyle\sum_k S(k)|\Delta\rho|^2}_{C}$$

自能 E_self(λ) = −α/√π Σ q_i(λ)² 与排除项 q_i q_j erf(αr)/r 同为 λ 二次型。每构象 **2 次铺展 + 2 次 forward FFT + 3 次网格归约**,之后全体 λ 的能量与 ∂E/∂λ = 2B + 2λC 解析求值。多分量 C 个电荷微扰分量:铺展/FFT 各 C+1 次,交叉项 C(C+1)/2 个(RBFE 中 C 通常 1–2)。

**适用条件一(倒空间)**:电荷是调度函数的仿射函数(q(λ) = q₀ + Σ g_c(λ)Δq_c;非线性调度如 f(λ)ρ₀ 秩一情形同样覆盖)——超出此条件的电荷调度会静默破坏该展开,ingest 须拒绝。

**适用条件二(直空间,Q-007 的真正承重假设):λ 依赖局域性**。软核 LJ 对 λ 非线性,无法展开,必须逐 λ 重算——之所以只贵 3–5×,靠的是「只有炼金原子参与的对随 λ 变化,环境–环境对(>99%)完全 λ 无关,逐 λ 重算只扫炼金子集」:

$$\text{cost}(u_{kn})/\text{cost}(U) \approx 1 + c_1\frac{L\,N_{\text{alch}}}{N} + c_2(C{+}1) \quad (N_{\text{alch}} \approx 50 \Rightarrow \text{直空间开销} \approx 4\%)$$

**REST2/β 缩放对整个溶质(含近程溶剂)生效,λ 依赖不再局域,此式失效**——激活 backlog 里的 REST2 会静默把 Q-007 从 3–5× 放大到接近 L 倍(雷区 #15)。**M16**:二次型求值 ≡ 逐 λ 朴素 FFT(**双门**:rel < 10⁻¹² ∨ abs < 10⁻⁹;Q16.48 铺展的网格量化在近相消体系上使纯 rel 门不可达——E(2q)=4E(q) 精确成立证明泛函二次齐次,残差是量化非加性,实测地板 ~4e-11;朴素实现留作 oracle);**M17**:∂E/∂λ ≡ 中心差分(双门:rel 10⁻⁶ ∨ abs 10⁻⁹)。

**网格尺寸规则**:目标间距 0.10–0.12 nm 由盒尺寸推导,向上取 FFT 友好因子(2^a 3^b 5^c 7^d)。「静态形状」的条件是给定体系。

### 5.2 共享邻居列表 + masking 位级严格(柱 5)

所有副本共用一份列表;重建判据 `max_{a,r} |x − x_ref| > d_thresh`;构建用全体副本坐标并集(超集保证)。

**masking 三条要求**(柱 5 的实现含义):

| # | 要求 | 承重理由 |
|---|---|---|
| 1 | 超 cutoff 贡献必须**精确为 +0 或缺席**;实现采用**乘 0**;**禁止依赖 erfc 自然衰减**(erfc(αr_c) ≈ 10⁻⁵,非零) | 位级:+0 与缺席在整数累加下等价,两者皆可;erfc 尾巴不可。乘 0 的选择理由 = 无分支(§2.1 性质③:replica 内层 ⇒ 同 warp 含不同副本 ⇒ 各副本 r² 判定不同,逐副本 if 必然分歧)——**引用的是布局前提,不是「零分歧」结论** |
| 2 | 判据与力计算用**同一个 r²**(共用寄存器值) | 两次独立计算(不同指令序/FMA 收缩)可给出不同边界归属 |
| 3 | r² = r_c² 的归属**编译期固定**(`<` 或 `<=` 写死) | 任何两个都是超集的列表必须给出相同力;正当性来自对抗性边界注入测试,**不是自然发生** |

**masking 严格 ⇒ 列表内容不进语义 ⇒ 重建时机/K 不进语义**(I-021)。

**skin 预算(Q-005)**:skin = 2·d_thresh + s_window(K) + margin = 2×0.05 + 0.12 + 0.06 = **0.28 nm**。s_window 是**性能参数非正确性参数**(实测 max 有极值统计偏差,尾部指数衰减下样本 max 系统性低估)——正确性由下节 flag 回滚机制单独兜底。**重建率按物理时间与步长无关**(t_rebuild ∝ d_thresh²/D,扩散主导);每 step 越界概率 ∝ 步长。

**C1 三层机制**(graph 重放窗口内的列表有效性):

1. skin 预算显式分解(上式,含 margin 项)
2. 积分 kernel 内每步 max-displacement 归约 + device flag;重放结束 host 检查;触发则**窗口作废,回滚到窗口起点 checkpoint(仅 x,v,138 MB;F 不存,回滚后重算),缩短 K 重跑**。flag 触发是性能事件不是正确性事件。回滚语义中立性由柱 5 保证
3. **M13**:构造窗口中段必然触发重建的初始条件(压低 skin),断言 flag 触发 + 窗口作废 + 最终轨迹 ≡ 每步检查的参考实现;**M14**:关闭安全机制断言与开启时力出现可检测差异(**从不触发的安全检查等于没有**)

### 5.3 LJ 侧规格

- **cutoff 1.0 nm;不用 LJPME**(LJ 的 ε 几何混合不是线性,倒空间无法二次型展开);不用 switch 函数(若将来引入,switch 在 cutoff 处必须解析为 0 且导数为 0)
- **解析尾部修正**:E_disp = −2πN²⟨C₆(λ)⟩/(3V r_c³),⟨C₆(λ)⟩ 对所有对求平均且含 λ 缩放的 ε、σ。**随 λ 变**(被 decouple 的原子对有贡献),含 1/V(与雷区 #13 联动)
- A1/A2 断言**单独覆盖**尾部修正项(不混在总能量里,相对贡献太小会被淹没)

## 7. CUDA Graph

**动机(改写)**:
1. **结构性(主要)**:graph 强制了显式的 K 步窗口边界——本设计中**唯一的 host 可见时间量子**。C1 的 flag 检查与窗口回滚、M2 等价断言、B10 粘滞标志检查、HREX 决策、checkpoint、u_kn 落库全部对齐到它。没有 graph 也要人为定义这个边界,graph 让它成为架构的一部分

```
loop:
  rebuild_neighborlist()      # host,数据依赖分支,仅窗口边界
  graph_replay(K steps)      # 一次 launch
  maybe_hrex_swap()          # host,每 ≥1000 步(见 §8.2 定标)

```

## 8. HREX(单卡最大红利)

### 8.1 交换 λ 而非坐标 = 交换 state(§4.4 表)

坐标/速度留 slot,λ 向量 + ALF 系数 + 累加器归属在 slot 间置换,permutation 日志全局。跨卡时(若将来)坐标按副本驻留,λ 交换后副本↔λ 对应关系跨卡错配——仍是拓扑问题,不是「几十个 double」。

### 8.2 拓扑:2 × 24 独立交换网络

**Gibbs 全对交换耦合两个 repeat 后,「独立重复」语义消失**(基于独立链一致性的收敛诊断与调度器杀任务逻辑全部失效)。**选 2×24**:两条独立链的 ΔG 差异是唯一不依赖 τ_int 估计的收敛证据(HREX 下 τ_int 估计出名不可靠);24 副本内全对 Gibbs 已远强于相邻交换。MSλD(连续)与 HREX(离散)**互斥**(配置层强制;嵌套需专门移动类型 + 细致平衡推导,backlog)。

**u_kn**:两个 24×24 块;MBAR 合并解(两链样本并作 24 态样本,合法且方差更小),两链分别解作收敛诊断。**交换步 ≡ 能量计算步**(B9):交换判据必须用当前构象能量,只算被 propose 的元素(二次型展开下很便宜);全矩阵每 M ≫ 交换间隔 步落库。

**交换频率**:由往返率实测定标,**1000 步为起点**(v1.1.2 修订;v1.1 的 50–100 步被三路证据推翻):

1. **M3 实测**:交换间隔 20 步(40 fs)时接受率 100% 假象——构象永远偏离自己态的平衡,样本全部无效;间隔 ≥ 构象弛豫时间后才恢复正常(v1.1 引用的「100–200 fs 收益饱和」是**能量**去相关,不是**构象**弛豫——两者差一个量级,这是当初把 Fusion 的 minor 采纳过头了);
2. **CpHMD REX 实践经验**(用户):交换间隔至少 1000 步;
3. **物理**:λ 交换后构象必须在新态下重新平衡——溶剂介电响应(水 Debye 弛豫 ~8 ps)是主导时间尺度,在 4 fs 步长下 ≈ 2000 步。

「单卡零成本 ⇒ 激进加密」的收益上限由构象弛豫时间决定,不由交换成本决定。

### 8.3 收敛与验证

- 新收敛指标:往返率、λ 占有率均匀性、λ 轨迹 τ_int、bootstrapped MBAR 不确定度;两链一致性保留
- **A7a**:双态谐振子解析接受率;**A7b**:交换开/关下每 λ 边缘分布一致(KS)——HREX 不改变态的平衡分布,这是全部正确性内容;**A7c**:接受率 vs 理论重叠;**A7d**:往返时间分布、占有率 vs MBAR 权重

### 10.2 批量红利(E0b 实测定标 2026-08-28)

$$\text{红利} = \frac{\eta_{\text{batch}}}{\eta_{\text{serial}}} \times f_{\text{amortize}}$$

- η_serial、η_batch:**E0b 已实测**(2026-08-28,Q-004b/4c):直空间(f64,intrinsic erfc 口径)η_serial 8.7% → η_batch(R=48)18.3%,**红利 2.10×** = occupancy 恢复(单副本 MD 延迟/访存受限,实测确认);FFT 128³ per-transform 时间与 batch 无关(~0.28 ms,~480 GB/s,带宽受限)⇒ **FFT 红利 ≈1.0**——「两种红利故事不同」的预测获实测确认。§10 v1.0 的 130–250 ns/day 单副本参考与「occupancy ≈ 0」结论同样无实测依据,均不进 spec
- 摊薄项 f_amortize ~1.10–1.15×(列表构建 ÷48 一项即撑住;launch 3–6%;参数广播 3–7%)
- 直空间红利 = occupancy 恢复(单副本 MD 是延迟/访存受限);FFT 红利 = 摊薄 + 转置效率,工作集(805 MB)远超 L2 可能带宽受限——**两者的红利故事不同,必须分开测**

### 10.3 M2 验收(混合门)

1. **硬地板(物理的,带量纲)**:

$$\text{Throughput}_{\text{batch}}\ [\text{ns/day}] \;\ge\; R \times \text{Throughput}_{\text{serial}}^{\text{baseline}}\ [\text{ns/day}] \times f_{\text{amortize}}^{\min},\quad f_{\text{amortize}}^{\min} = 1.10\text{–}1.15$$

   低于地板 = 实现 bug,无辩解空间。η(无量纲 achieved % of peak)只出现在归因段,不进地板定义——地板比较的是**同量纲吞吐**。

   **基线来源纪律(地板的牙齿所在)**:Throughput_serial^baseline = max(E0a 的 OpenMM double 路径, E0b-direct 微基准 R=1 上界)。**当前锚定(2026-08-28):E0a OpenMM double = 136.0 ns/day @2fs(60k 原子)**;E0b-direct R=1 上界换算远低于此(intrinsic erfc 慢路径),故地板基线 = 136.0 ns/day @2fs,若 M2 前出现更快外部可核验参照再取 max。(它是语义 oracle 不是性能基线;地板若可用慢基线自动通过,就不配说「无辩解空间」)。**地板基线必须是外部可核验的实现或本项目的上界型微基准,不能是被测路径自身的产物**——与 §11.0「oracle 不能由被测方定义」同一条原则的性能侧版本。

2. **地板之上归因门**:与 E0b 预测区间的偏离必须归因并写进 §14,不设斩杀线
3. **破环路径**:Throughput_serial 由上述基线来源测;η_batch 上界由孤立微基准(批量 cuFFT 吞吐 + 直空间对循环 RawKernel)——循环降级为「上界估计需要两个一天级微基准」

**地板抓谎言,归因抓意外。** 这是全 spec 的 gate 设计原则;每条 gate 在 §11 标注 地板/归因 × 地基/探测器/监护,未标注视为未定义。**所有验收判据必须以带量纲的不等式书写**(§14.6 规则,m4b 的 k_BT/ns/dof 合格,A4 判据见 Q-015)。

### 10.4 评估规则

benchmark 参数随机化(体系大小、密度、三斜盒、离子浓度、λ 窗口数——**在 R 实例化集合内**),报告最差情况;顶层指标 = 每 GPU-day 产出的收敛 ΔG 数量;ns/day 仅日级代理。f32 杠杆与批量红利**同量级且相乘**(E0d 已实测:直空间 2.84×,FFT 带宽受限近无效,分部件加权后 ~1.4× 量级——见开放项 1 关闭记录)。

### 14.6 流程规则

- **patch header 触发行声明**:新增/修改/回查未受影响的 Q-xxx/I-xxx 逐条列出,未列全不予合入
- **CI 反向索引**:从声明提取被改量,反查以其为触发条件的行,要求显式声明处置
- **UNSOURCED 阻塞**:CI 检查表中 UNSOURCED 行数;Q-008/Q-009/Q-010 类阻塞 M0,**Q-015 阻塞 M4**
- **合并稿适用完整流程 + 交叉引用一致性检查**:任何形如「这也是 X 的理由」的跨节引用,两侧必须同时列出被引用的**前提**(而非结论),CI 检查前提文本一致——V1(零分歧引用)即此类缺陷的首个回归用例
- **表外数字不受保护**:§10/§11 正文中的每个数字断言/不等式,要么提升为 Q-xxx(推荐,失效触发自动连入反向索引),要么显式标 `non-load-bearing`;两者皆无 = CI 失败
- **error ≠ fail**:基线/manifest 不匹配报 error(无法判定),断言不成立报 fail
- **draft 到期**:雷区 #014 的每个 mutation pattern 在其 target 代码落地的同一 PR 内实例化,未实例化则该 PR 不予合入

## 15. 附:设计信条(v1.1 修订)

1. **先有慢而正确的语义定义,再让它变快**——且语义定义必须**结构同构**于目标实现(M0 双交付)。「语义与实现无关」只在解耦处成立,而铺展/barostat/性能账恰恰是耦合点
2. **副本为最内层维度。** 换来的是指令流结构一致、访存合并、列表可共享;分支判定跨副本不一致(坐标独立),masking 因此必须无分支
3. **累加器无条件定点**——力与电荷网格同柱;位级确定性是所有变形测试与统计地板门的地基
4. **masking 位级严格**——列表内容不进语义,K 与重建时机因此自由
5. **容量并行 > 能力并行**;交换 λ(state)而非坐标(slot)
6. **把维里从关键路径移走**;引擎永不存在的还有:多副本 barostat、时钟依赖、float atomic
7. **u_kn 是顺路产物而非额外开销——在两个条件下**:电荷仿线性(倒空间可展开)+ λ 依赖局域(直空间只扫炼金子集)。任一破坏(REST2、非仿射调度)则此信条失效(雷区 #15)
8. **地板抓谎言,归因抓意外**——gate 的职责是抓住「错了但不知道」,不是替未测量的事物许愿
9. **探测器不是保证,压力源必须由风险通道推导**——保证只能来自构造
10. **理由对了,将来才有人知道什么时候可以违反它**
