# 005 · 条件性成立的近似(conditional_approximations)

## 为何脆弱
本域收集**所有"近似只在特定条件下成立"的知识**:倒空间对电荷的二次依赖
(网格/插值阶数选择的前提)、截断与 switch 函数的成立域、热力学积分端点的
可积性、BAR/MBAR 的重叠条件……共同特征:LLM 记结论忘前提,且违反前提不报错。

## 状态:NO-ORACLE(演示)
当前没有解析 oracle 可写——这类知识的第一步处置不是测试,而是:

1. 黑盒红队对该域提 gap(缺什么规格才能测);
2. 你决策:补规格推导 / 硬编码为前置条件检查 / 接受风险并记录。

本条目故意不带 `## mutation` 块:种子变异体只来自可判定的域。
等某一子项有了 oracle,从本域拆出、立新条目。

## enforcement
- no-oracle: 依赖 gap 标记流程(黑盒产 gap → 决策表 → 硬编码或补 oracle)。
